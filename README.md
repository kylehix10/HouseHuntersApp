# HouseHunters

HouseHunters is an Android mobile application that allows users to search for and discover rental houses and rooms. The application provides users with a simple way to browse available properties and view information about potential rentals.

## Features

* User registration and login
* Search for available rental properties
* Browse houses and rooms
* View property details
* User-friendly Android interface
* Backend integration for storing and retrieving application data

## Technologies

* **Kotlin** — Android application development
* **Android Studio** — Development environment
* **Azure** — Backend and cloud services
* **REST APIs** — Communication between the application and backend services

## Application Architecture

HouseHunters uses a mobile client and cloud-based backend architecture. The Android application is responsible for the user interface and user interactions, while the backend handles application data and communication between the client and server.

```text
Android Application
       │
       │ REST API
       ▼
   Azure Backend
       │
       ▼
  Application Data
```

## Getting Started

### Prerequisites

* Android Studio
* Android SDK
* Kotlin
* Android device or emulator

### Installation

1. Clone the repository.

```bash
git clone <repository-url>
```

2. Open the project in Android Studio.

3. Allow Android Studio to download and configure the required dependencies.

4. Configure the required backend/API settings.

5. Build and run the application using an Android emulator or connected Android device.
